UniFlix Study Assistant

Privacy Policy

Last updated: 15 September 2026

UniFlix Study Assistant is an independent browser extension designed to help users organize and study lecture videos available on UniFlix.

Data stored by the extension

The extension may store the following information locally in the user's browser:

  • Lecture page URL and lecture title.
  • Playback position, lecture duration, playback speed and last watched time.
  • User-created notes and bookmarks with timestamps.
  • Favorite lectures/courses, SOS lectures and “watch later” selections.
  • User-created lecture lists and list names.
  • Extension settings such as panel size, UniFlix viewing size, auto-resume and layout preferences.

How the data is used

This information is used only to provide the extension's user-facing features, including resume playback, progress tracking, notes, bookmarks, favorites, SOS lectures, watch-later lists, custom study lists and interface preferences.

Local storage

Data is stored locally using Chrome extension storage. The extension does not require a separate account and does not send stored study data to the developer's servers.

Screenshots

If the user chooses the screenshot feature, the image is generated on the user's device and downloaded locally. It is not uploaded to the developer or to a third party by the extension.

Website access

The extension requests access only to https://uniflix.uoa.gr/* so it can interact with the UniFlix lecture video player and provide its study tools.

Data sharing and sale

UniFlix Study Assistant does not sell user data and does not transfer user study data to advertisers, data brokers or other third parties.

Personal and sensitive information

The extension does not intentionally collect names, email addresses, passwords, authentication credentials, payment information, health information or precise location data.

Data deletion

Users can remove stored data using the extension's data-management features or by removing the extension from the browser.

Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Independent project

UniFlix Study Assistant is an independent and unofficial project. It is not affiliated with, endorsed by, or an official product of the National and Kapodistrian University of Athens or UniFlix.

Changes to this policy

This policy may be updated when the extension's features or data practices change. The latest version will always be published at this URL.
